# panelaelmanzan
Proyecto web  panela el manzano interactivo creado con HTML, CSS y JavaScript. Incluye una barra de navegación animada, video generado por IA, línea de tiempo interactiva, secciones de herramientas y tecnologías con animaciones, y pie de página. Usa recursos como LottieFiles, Flaticon e IA para una experiencia funcional y dinámica.
